# PVZ 图片自动化任务 APK（Android 原生）

## 当前功能
- 项目管理：可以创建、切换多个自动化项目。
- 步骤编排：每个项目包含多个有序步骤，按顺序执行。
- 多图识别：每个步骤可以添加多张模板图片；默认采用“任意一张启用图片匹配成功即执行”。
- 图片规则：每张图片可单独启用/停用、删除并设置匹配阈值（当前默认 0.88）。
- 步骤延迟：点击手势完成后等待步骤配置的延迟（默认 1000ms）再进入下一步。
- 项目循环：可切换项目完成后是否从第一步重新开始。
- 屏幕捕获：MediaProjection + ImageReader。
- 图像识别：OpenCV `matchTemplate` 灰度模板匹配。
- 点击执行：AccessibilityService `dispatchGesture`，检查手势提交、完成和取消状态。
- 运行诊断：广播输出屏幕捕获、匹配、点击和异常状态；不再静默吞掉识别异常。
- 旧版平铺图片规则会迁移到“默认项目 / 步骤 1”。

## 环境
- Android Studio Ladybug 或更新版本
- JDK 17
- Android SDK 35
- Gradle 8.7（GitHub Actions 自动安装）
- Android 8.0（API 26）及以上

## 导入与编译
1. 解压项目，在 Android Studio 选择 Open。
2. 等待 Gradle Sync 完成。
3. 真机安装调试时可使用 USB 调试；APK 安装后运行不需要连接电脑。
4. Build > Build Bundle(s) / APK(s) > Build APK(s)。
5. APK 默认输出到 `app/build/outputs/apk/debug/app-debug.apk`。

## 使用
1. 打开 App，进入系统无障碍设置，启用“PVZ 图片自动点击”。
2. 新建项目，点击“添加步骤”，输入步骤名称。
3. 选中要添加图片的步骤，再点击“添加识别图片”，从相册选择裁剪好的模板。
4. 为后续动作继续添加步骤和模板。一个步骤中任意一张启用模板匹配成功即点击；点击完成后进入下一步。
5. 按需开启项目循环，然后点击“开始项目”，在系统弹窗中允许屏幕录制。
6. 切换到目标游戏。运行状态会显示在 App 页面；点击“停止”结束任务。

## 点击无响应排查
- 必须先在系统设置中启用本 App 的无障碍服务，并返回 App 确认服务连接。
- 开始项目时必须同意屏幕录制授权。
- 运行日志如果持续显示“等待屏幕帧”，检查系统是否允许屏幕捕获。
- 显示“识别成功，但无障碍服务未连接”时，重新开启无障碍服务。
- 显示“匹配不到图片”时，检查模板是否来自同一分辨率/方向的画面、是否过大或包含动态背景，并调整阈值。
- 显示“点击手势被系统取消”时，检查系统无障碍权限、游戏当前窗口和厂商后台限制。

## 模板建议
- 使用与游戏当前画面相同方向、相同分辨率比例的截图。
- 模板尽量紧贴按钮，包含辨识度高的边缘、文字或图标。
- 避免大面积动态背景；同一按钮的不同状态分别制作模板。
- 阈值越高越严格；误点时提高阈值，漏识别时适当降低。

## 当前版本限制
- 同一步骤采用 OR 逻辑：任意一张启用模板匹配成功即执行；尚未提供 AND、多条件组合和失败分支。
- 步骤按顺序推进；暂未提供步骤跳转、条件等待、点击次数限制和坐标手动校准。
- 模板匹配为灰度单尺度匹配，对缩放、动画、透明遮罩和分辨率变化不够鲁棒。
- 项目循环会在最后一步完成后重新从第一步开始；请谨慎使用，避免在非预期界面重复操作。
- 请先在非关键界面测试，遵守目标应用/游戏服务条款。

## GitHub Actions 云端编译
1. 将项目根目录内容（包括隐藏的 `.github` 文件夹）上传到自己的 GitHub 仓库。
2. 推送到 `main` 或 `master`，或在 Actions 页面手动运行 `Build PVZ AutoClicker APK`。
3. 在成功的 workflow run 的 Artifacts 中下载 APK。
4. 当前产物为 debug APK，不是面向应用商店发布的 release 包。
